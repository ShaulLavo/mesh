# Internal working notes

This folder holds plans, task briefs, per-task audits, review notes, benchmark
results, and fixture screenshots from building Mesh. It is not user documentation
and may be out of date: the code and `docs/` are the source of truth. An item
leaves when its plan is finished and either turns into a page in `docs/` or an ADR in
`docs/adr/`, or gets deleted. Git history keeps everything that is deleted.
